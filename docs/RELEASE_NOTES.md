# Map Skill v1.0.0

Map Skill is an MIT-licensed route-planning workflow for ChatGPT and Codex.

Highlights:

- Universal public-transit-first skill with walking, driving, cycling, urgent, comfortable, leisure, low-transfer, and rail-first handling.
- Enhanced İstanbul edition using bounded official IBB, IETT, Metro İstanbul, Şehir Hatları, Marmaray, traffic, event, weather, opening, and fare checks.
- Sixteen city editions with official-source metadata, access/licence boundaries, and honest coverage gaps.
- Capability-aware links for Google, Yandex, Moovit, HERE, Bing, Apple, Waze, Citymapper, and OpenStreetMap.
- Local standard-library helpers for route normalization/scoring, ETA comparison, multi-stop ordering, weather sampling, link resolution, source selection, and consent-gated preferences.
- Git-backed plugin marketplace, standalone ZIPs, deterministic packaging, manifest, SHA-256 checksums, tests, and CI.

No paid API is required. Keyed sources are optional and are never reported as queried unless credentials are configured and the call succeeds.
