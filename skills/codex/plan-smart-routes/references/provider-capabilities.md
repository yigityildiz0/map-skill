# Provider Capability and Link Matrix

Verified against official documentation on 2026-07-31. Treat provider pages, products, coverage, and URL behavior as changeable; reopen the cited documentation when precision matters.

## Critical distinction

A **navigation/deep link** opens a product with encoded fields. It does not retrieve a route, ETA, fare, traffic state, or all provider alternatives. A proprietary **routing API** returns route data but may require credentials, billing, licensing, or an account.

Never describe link generation as `get_*_routes` or `get_*_route_matrix` success.

## No-key link capabilities

| Provider | Origin + destination | Intermediate stops | Mode | Trip time | Main limitation |
|---|---|---|---|---|---|
| Google Maps URL | Yes; labels or coordinates | Yes; up to 3 in mobile browsers, 9 otherwise | driving, transit, walking, bicycling, two-wheeler | No | URL maximum 2,048 characters; opened result must be checked |
| Yandex Maps web | Coordinates | Documented schema only start/end | driving, transit, walking, bicycling | No | Transit availability is city-dependent |
| Yandex Navigator app | Coordinates | Yes, `via_0...n` | driving | No | App-only; unsigned launch rate limit |
| Moovit app | Coordinates + labels | No | transit planner | `date`, but depart/arrive semantics are undocumented | Moovit app required |
| Moovit web | Destination only | No | transit destination planning | No | Requires the correct `metroId`; does not preserve origin |
| HERE WeGo share | Coordinates | Yes; documented maximum 100, practical recommendation 50 | driving, walking, transit, bike and more | No | Verify regional coverage/opened result |
| Bing custom map URL | Yes | Multiple route points | driving, transit, walking | Yes | Product/coverage is a fallback; legacy Bing routing stack is being retired |
| Apple Map Links | Yes | No | driving, walking, transit | No | Official parameter document is archived from 2017 |
| Waze | Destination only; starts at device location | No | driving | No | Cannot preserve supplied origin |
| Citymapper | Yes, coordinates | No | product chooses multimodal options | No | City coverage; self-service API discontinued |
| OpenStreetMap directions | Coordinates | This helper uses two endpoints | driving, walking, bicycling | No | No documented native transit mode; community backends/no SLA |
| Transit custom scheme | Yes | No | transit product | No | App scheme only; not generated by the helper by default |

## Documented patterns

### Google Maps

```text
https://www.google.com/maps/dir/?api=1&origin=...&destination=...&travelmode=transit&waypoints=A%7CB
```

`api=1` is required. Maps URLs have no documented departure/arrival-time parameter. Source: [Google Maps URLs](https://developers.google.com/maps/documentation/urls/get-started).

The Routes API can compute timed transit routes and matrices, but it requires an API key or OAuth plus enabled billing. It is not part of the zero-setup path. Sources: [transit routes](https://developers.google.com/maps/documentation/routes/transit-route), [usage and billing](https://developers.google.com/maps/documentation/routes/usage-and-billing).

### Yandex

```text
https://yandex.com/maps/?rtext=41.0082,28.9784~41.0422,29.0083&rtt=mt
```

For `rtext`, coordinates are latitude,longitude. `rtt=auto|mt|pd|bc`. The documented web schema encodes only origin and destination and no trip time. Source: [Yandex Maps web URLs](https://yandex.com/dev/yandex-apps-launch-maps/doc/en/concepts/yandexmaps-web).

Driving with intermediate points can use:

```text
yandexnavi://build_route_on_map?lat_from=...&lon_from=...&lat_via_0=...&lon_via_0=...&lat_to=...&lon_to=...
```

Source: [Yandex Navigator URL parameters](https://yandex.ru/dev/navigator/doc/ru/concepts/navigator-url-params). Yandex documents an unsigned app-launch limit of roughly five clicks per device in 24 hours before web fallback; signed commercial use needs an access key. Sources: [Maps commercial use](https://yandex.com/dev/yandex-apps-launch-maps/doc/en/concepts/yandexmaps-commercial-use), [Navigator commercial use](https://yandex.ru/dev/navigator/doc/ru/concepts/navigator-commercial-use).

In İstanbul, honor the user’s preference to use Yandex as a road-traffic/driving sanity check. Do not turn that preference into a universal transit claim: Yandex’s current published transit-city list does not list Turkey. Source: [Yandex transit cities](https://yandex.com/support/m-maps/en/cities-list).

### Moovit

```text
moovit://directions?orig_lat=...&orig_lon=...&orig_name=...&dest_lat=...&dest_lon=...&dest_name=...&auto_run=true&date=ISO8601&partner_id=plan-smart-routes
```

Source: [Moovit deep linking](https://moovit.com/developers/deeplinking/). The official document does not define whether `date` means departure or arrival; keep the text plan authoritative and warn when that distinction matters. The scheme has no documented intermediate stops.

Moovit’s public transit API requires an API key and licensed HMAC signing; do not call it without existing authorized credentials. Source: [Moovit Public Transit API](https://api-docs.moovit.com/api-docs/5.1/MoovitPublicTransitAPIs.html).

### HERE WeGo

```text
https://share.here.com/r/41.0082,28.9784,Origin/41.0256,28.9741,Stop,s/41.0422,29.0083,Destination?m=pt
```

Modes include `d`, `w`, `pt`, and `b`; `s` marks a stop. The share format has no trip-time field. Source: [HERE WeGo route sharing](https://docs.here.com/wego-pro/docs/share-route-dl).

### Bing

```text
https://bing.com/maps/default.aspx?rtp=adr.A~adr.B&mode=T&limit=A&time=202608010900
```

`mode=D|T|W`, `limit=D|A`, and `time=YYYYMMDDhhmm`. Source: [Bing custom map URL](https://learn.microsoft.com/en-us/bingmaps/articles/create-a-custom-map-url). Bing Maps REST is closed to new free customers and Enterprise retires on 2028-06-30, so the URL is a fallback whose opened coverage must be verified. Source: [Bing Routes retirement](https://learn.microsoft.com/en-us/bingmaps/rest-services/routes/).

### Apple, Waze, Citymapper, OSM

- Apple: `https://maps.apple.com/?saddr=...&daddr=...&dirflg=r`; no stops/time. Source: [Apple Map Links archive](https://developer.apple.com/library/archive/featuredarticles/iPhoneURLScheme_Reference/MapLinks/MapLinks.html).
- Waze: `https://waze.com/ul?ll=lat,lon&navigate=yes`; destination/current-location driving only. Source: [Waze deep links](https://developers.google.com/waze/deeplinks).
- Citymapper: `https://citymapper.com/directions?startcoord=...&endcoord=...`; no stops/time and city-dependent. Sources: [directions link](https://citymapper.com/news/2386/launch-citymapper-for-directions), [API closure](https://citymapper.com/news/2596/sdks-and-apis-come-to-an-end).
- OSM: use its web directions only for supported road/walk/bike engines. Attribute OpenStreetMap and its contributors. Source: [OSMF attribution guidance](https://osmfoundation.org/wiki/Licence/Attribution_Guidelines).

Apple’s current public-transport availability list does not list Turkey. Transit’s current coverage list also does not list Turkey. Sources: [Apple feature availability](https://www.apple.com/uk/ios/feature-availability/), [Transit coverage](https://transitapp.com/en/region).

## Link selection rules

1. Generate links only after exact places and order are known.
2. Return Google, Yandex, and Moovit first only when each can preserve the needed fields and cover the mode/area.
3. For a transit multi-stop block, prefer Google/HERE/Bing links. Omit Moovit/Yandex web rather than dropping stops silently.
4. For a driving multi-stop block, Google/HERE/Yandex Navigator/Bing are candidates.
5. If the link cannot encode trip time, say the text plan’s date/time is authoritative.
6. App-only schemes may not render as clickable in every chat client; include a web alternative when it preserves the trip.
7. Test or inspect the final opened link where tools allow. Otherwise state that availability must be checked.

Use `python scripts/route_toolkit.py links ...` to encode and disclose limitations consistently.
