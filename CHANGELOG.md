# Changelog

All notable changes are documented here. This project follows Semantic Versioning.

## 1.0.0 - 2026-07-31

- First public release of the Universal route-planning skill.
- Enhanced Istanbul edition with bounded official IBB, IETT, and Metro Istanbul checks.
- Official-source profiles for complex transit cities across Europe, Asia-Pacific, and the Americas.
- Deterministic link generation, route normalization/scoring, ETA comparison, multi-stop optimization, weather sampling, and consent-gated preferences.
- Plugin manifest, standalone skill packages, validation workflow, checksums, and source manifest.
